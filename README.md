# MSXcratch - MSXをブロックプログラミングで楽しむ Gen.2

<img src="./data/gen2_screen.jpg" alt="実行画面" height="480">

## 何ができる？
GoogleのBlocklyを利用することで、MSX BASICのソースコードをブロックプログラミングで吐き出せます。

Gen2では、引数部分に**戻し値を持つ命令**をドロップできるようになりました。
これにともない、MSX BASICの戻し値を持つ命令の多くに対応しました。

Scratch感覚でMSXのコーディングができる環境をお楽しみください。

※旧バージョンについてはGen1ディレクトリを参照ください。

## できること
- ブロックプログラミングの結果をMSX BASICのソースコードとして吐き出せます。
  - 例えば、クリップボードにコピーした後、MSX0に繋がっているターミナルソフトにペーストしたり、WebMSXにAlt+V→Ctrl+Vすればすぐに実行できます。

- BASICコンパイラ『MSXべーしっ君』が対応している命令は概ねカバーしています。**『MSXべーしっ君』が利用できる環境（MSX0など）であれば、ブロックで作ったプログラムが爆速で動きます。**

- ブロックIFや条件付きループ、ラベルつきサブルーチンに対応しているため、**行番号に依存しないコーディング**が可能です。
  - ただし、サブルーチンでローカル変数が使えるわけではありません。

- ブロックプログラミングでは単純な文法エラーが発生しないため、初心者向きです。
  - 見た目はScratchなので、**プログラミング教育を受けた令和の小学生がMSX用のプログラムを書ける**かもしれません。

- コーディングがちょっとだけ楽になる機能を用意しています。
  - スプライトパターンをチェックボックスで定義できます。
  - エラー処理を簡素化できるエラートラップブロックを用意しています。
  - 書いたそのままをコードとして出力する「即値」ブロックを用意。ブロックとして用意していない命令や関数もコーディングできます。

## 注意事項
- メイン処理は「RUNされたとき」ブロック内に記述してください（他言語のmain()相当）。
  - Blocklyではメイン処理以外のコードが先に出力される場合があり、それを防ぐために用意しています。『MSXべーしっ君』にてCALL RUNによって実行する場合はDIM文を記述可能な位置が限定されるため、その対策として用意しました。

- 『MSXべーしっ君』を利用する際は、『MSXべーしっ君』の制限事項に従ってコーディングしてください。
- 「_」（アンダースコア）が2つ以上並ぶ文字列を使わないでください。内部処理でラベルを行番号に変換するために使用しています。
- oで始まる変数は使用しないでください。内部処理で使用しています。
- たいていのブロックプログラミング環境では、変数もブロックとして作成しますが、泥臭く手で変数名を打って下さい。
  - ＄つきの変数名（A＄など）のエスケープがどうしてもうまくいきませんでした（A_などに変換されてしまう）。GrokやChatGPTの言うとおりにしても解決せず、継続調査中です。
- 「令和の小学生がMSX用のプログラムを書けるかも」と前述しましたが、以下の点に留意ください。
  - MSX BASICの仕様について多少の知識が必要です（例：座標系、カラーコード、数値の範囲、文字列と数値の区別等々）。
  - MSX BASIC上で実行エラーが発生した際、発生箇所がブロック上のどの部分かを特定するにはMSX BASICの知識と開発経験が必要となります。
  - 現実的には、ピクセル環境のプログラミングに興味を持つ小学生（実際にいる）とMSX BASIC経験者がペアプログラミングする必要があるかと思われます。
    - やっとプログラミング教育の世の中が来たんだし、40年以上前にMSXを教育に使おうとした先人たちの夢を追い続けたいじゃん（例えば『パーソナル・コンピュータMSXの学習指導への利用―基礎から教室での実践まで』（平田 啓一 編集, 東京書籍, 1985）みたいな……）。
